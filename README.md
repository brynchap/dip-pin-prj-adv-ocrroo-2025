# Overview

Include a brief overview of the project, include:

- How do you deploy and run the project?
in powershell navigate to the project file root. Then run `fastapi dev preliminary/fast_api.py`. My project url is "http://127.0.0.1:8000" 

- What are its core dependencies?
The core dependencies include: fastapi, numpy, opencv-python, pytesseract, pyttsx3

- Who is it for and why?
This Project is for users with vision impairments so they can hear the text onscreen which is otherwise not spoken.
